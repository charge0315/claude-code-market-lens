今日は東京市場がお休みなので、毎朝の検証ログはお休みして、自作の日本株アルゴリズム「ALPHA FORGE（アルファフォージ）」の1週間を、台帳の数字だけで振り返る週末版をお届けします。
3連休明けのたった2営業日で、日経平均は5日続伸。そんな週に、アルゴリズムは何を選び、何につまずいたのでしょうか。

1. 日経平均は週間で+2.07%（9月18日 65,018.95円 → 9月25日 66,364.20円）。TOPIXは+0.92%と、半導体などの値がさ株が指数を押し上げた週でした

3. 今週分の答え合わせはまだ0件です。台帳は「発行から7日たってから決着を確かめる」設計のため、来週から順番に結果が出はじめます

2. 📋 今週のアルゴリズム抽出銘柄（台帳の全記録）

［画像挿入位置：今週の抽出銘柄一覧表／ images/06_week_pick_table.png ／キャプション：9月22日〜25日に台帳へ記録した抽出銘柄（同じ銘柄・同じ区分は最新の記録を表示）］

※「審査員一致度」は、4つの分析（テクニカル・トレンド・業績・材料）が同じ方向を向いている度合いです（1.00に近いほど意見がそろっています）。

今週、台帳に記録した抽出は全部で20件でした。ただし同じ銘柄が何度も出てくるので、銘柄にすると9銘柄です。

・9月22日（火・休場日）：検証のための手動実行を2回行い、延べ12件
・9月23日（水・秋分の日）：実行なし
・9月24日（木）：朝の定期実行で6件
・9月25日（金）：朝の実行で2件（6時台に5802、7時30分の再実行で3905）

■ 同じ銘柄が何度も並んだ理由
285A（キオクシアHD）は中長期と短期で合わせて6回、9984（ソフトバンクG）・8001（伊藤忠商事）・4047（関東電化工業）は3回ずつ記録されています。
休場日の22日は株価が動かないので、同じ日に2回実行すれば、ほぼ同じ答えが返ってきます。さらに24日の朝も、参照する終値は連休前の18日のままでした。つまり「アルゴリズムが何度も確信を深めた」わけではなく、「同じ材料で何度も聞いた」結果です。記録の件数を数えるときは、この重複に注意が必要だと、自分への反省も込めて書いておきます。

3. 📊 台帳の答え合わせ（通算の決着状況）

当ラボでは、よい結果だけでなく、負けや「不成立」も含めて台帳の数字をそのまま公開しています。

■ 予測台帳の現状（2026/9/26 朝時点）
・台帳に記録した検証対象銘柄：通算84件（9月12日〜25日）
・決着済み：7件
・未決着：77件（今週の20件はすべてここに入っています）

■ 決着済み7件の内訳
シミュレーション上の約定が成立したのは2件です。
・5016（JX金属／9月13日の短期・正のトレンド相関（検証用））：1営業日後 +1.95%（勝ち）
・7203（トヨタ自動車／9月13日の短期・中立）：1営業日後 −0.30%、2営業日後 +0.30%

残りの5件は、株価がシミュレーション起点価格に届かず、約定が成立しなかった「不成立」です。
・9256（サクシード）：9月12日・13日の中長期の記録 計3件
・6787（メイコー）：9月13日の中長期
・6758（ソニーグループ）：9月13日の短期

この7件は、いずれも今週（9月23日〜26日）に決着の判定が出たものです。ALPHA FORGE は、起点価格で約定が成立しなかったものを勝ちにも負けにも数えません。勝ち負けがついたのはまだ2件だけなので、勝率を語れる段階ではありません。

■ 今週の抽出分は、いつ答え合わせされるの？
台帳は、株価が起点価格に届くのを待つ期間や、ホライズン（短期なら1〜3営業日後）の結果がそろうのを待ってから決着を確かめるため、「発行から7日たった記録」から順番に答え合わせの対象に入れています。
今週の20件は、22日の分から順に、来週から対象に入っていきます。結果が出たら、この欄で正直にご報告します。

4. 🤖 今週の「迷いと反省点（AI成長日記）」

【自信度が「採用ラインぎりぎり」に集中した】

今週の20件のうち、AIの自信度（確度）が50%を超えたのは、25日の5802（住友電気工業）の62%だけでした。残りの19件は40〜45%で、採用ライン（40%）をわずかに越えたものばかりです。
「迷いながらも、ぎりぎり残した」記録が多い週だったことになります。25日の朝に20銘柄のうち19銘柄を見送ったのも、同じ「自信のなさ」の表れでした。来週の答え合わせで、この「ぎりぎり組」がどんな結果になるのかは、アルゴリズムの採用ラインが妥当かどうかを確かめるよい材料になりそうです。

【日経平均が上がった週に「日経ベア2倍」を拾っていた】

いちばんの反省材料はこちらです。休場日の22日、短期の候補から1360（日経平均ベア2倍上場投信）が「正のトレンド相関（検証用）」として抽出されていました。
ベア型のETFは、日経平均が下がると値上がりするように作られた商品です。つまりアルゴリズムは「この商品が上がる＝日経平均が下がる」方向の仮説を置いていたことになります。ところが実際の日経平均は、24日・25日の2日間で大きく上昇しました。
台帳での答え合わせはこれからですが、少なくとも今週の相場の流れとは逆向きの仮説でした。個別株と同じ物差しで「逆向きに動く商品」を採点してよいのか。これは設計そのものを見直すきっかけとして、宿題に残しておきます。

■ 🛠️ 今週のALPHA FORGE 開発ミニ日誌

今朝、週末の定期点検で、ニュースの取得まわりの不具合が見つかりました。
ニュースの配信元へのアクセスが短時間に集中して一時的に拒否されたとき、システムはそれを「ニュースが0件だった」と誤って記録していたのです。影響を受けたのは、将来の学習に使うために貯めている「ニュース感情の記録」で、まだモデルの学習には使っていない段階でした。
私がシステムの稼働状況を点検していたところ、開発の相棒である Claude Code がログの異常に気づきました。原因の特定と修正は一緒に進め、「どこまで直すか」「誤った記録をどう扱うか」は私が決めています。

1. 「取れなかった」と「0件だった」を区別して、取れなかった分は記録しない
2. 拒否が続いたら、無理に取りに行かずにその日の収集を打ち切る
3. 1銘柄ごとに少し間をあけて、配信元に負担をかけないようにする

さかのぼって取り直せない9月20日の記録は、誤った「0件」を削除しました。派手さはありませんが、「データがない」ことと「データを取れなかった」ことを取り違えないのは、答え合わせを大切にするアルゴリズムにとって地味に重要な一線です。
