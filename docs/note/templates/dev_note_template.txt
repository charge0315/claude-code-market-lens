3. 🛠️ アーキテクチャと実装のこだわり（技術的ブレークスルー）

（課題をどう解決したのか。アーキテクチャ図、データフロー、設計原則を解説）

［画像挿入位置：システム構成図・アーキテクチャ図／ images/dev_architecture.png ］

■ 設計の3大原則
① 境界の徹底（データ隔離）：
外部由来のテキストは直接メインプロンプトに流さず、隔離されたLLMで数値・enumに変換してから渡す。
② 継続学習と未来リークの排除：
学習データは自分の予測実績のみを使用し、未来の情報が混入しない時系列ウォークフォワード検証を強制。
③ 高速・軽量な自律運用：
FastAPI + Celery + Redis + SQLite の堅牢なローカルスタックで、毎朝07:30の自動実行から下書き生成までを数分で完結。
